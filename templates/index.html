Conversor de áudio para uso pessoal

Ouça offline
o que você gosta.

Cole o endereço de um vídeo do YouTube e baixe o áudio em MP3, com capa e nome do artista.

Você também pode colar com Ctrl+V em qualquer parte da página ou arrastar o link para cá.

Como funciona

O programa roda no seu computador, usa o yt-dlp para buscar o áudio e o ffmpeg para converter. Sem anúncio, sem cadastro, sem enviar nada para servidores de terceiros.

Qualidade
MP3 a 320 kbps, a partir da melhor faixa de áudio disponível.
Capa e dados
A miniatura do vídeo vira a capa; título e canal vão para os metadados.
Playlists
Se o link tiver uma playlist junto, só o vídeo aberto é baixado.
Onde fica
Na pasta musicas/, ao lado do programa.

Perguntas

Parou de funcionar. O que faço?

O YouTube muda o site com frequência. Atualize com pip install -U yt-dlp e tente de novo.

Aceita link do YouTube Music?

Sim. Também aceita links curtos (youtu.be) e da versão para celular.

Dá para baixar várias de uma vez?

Pelo terminal, sim: python baixar_musica.py link1 link2 link3.

Posso baixar qualquer vídeo?

Baixe apenas o que você tem direito de usar e respeite os termos do YouTube e os direitos dos artistas.
